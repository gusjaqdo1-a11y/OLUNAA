# OLUNAA

Modern, privacy-first social messaging platform.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- Better Auth / email + username authentication
- WebSocket-ready realtime architecture
- Vercel deployment

## Product direction
OLUNAA combines messaging, social discovery, follows, communities, stories, calls, AI assistance, translation, cloud media and privacy controls in a fast, polished interface.
